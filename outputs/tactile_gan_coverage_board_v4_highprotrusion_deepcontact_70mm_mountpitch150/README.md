# v4 70 mm Coverage Board: 150 mm M6 Pitch

This is a non-destructive mounting-hole variant of the original v4 deep-contact board. Each of the four 170 x 170 mm tiles keeps the same tactile geometry, STL-local frame, URDF frame and sampling CSV as v4. Only its four M6 clearance holes changed.

## Hole pattern

Every tile uses local hole centres `(-75,-75)`, `(-75,75)`, `(75,-75)`, `(75,75)` mm. The horizontal and vertical centre-to-centre pitch is therefore exactly `150 mm`. The nominal M6 hole diameter is `6.0 mm`.

The calibration dock for this variant attaches to one edge pair at local Y = -75 mm.
